## Baseline and implementation

Verified the checkout had only synth/V001 and the two-domain generator, with T7's interim
latent.py and latent_archetypes interface. edge_cases.py, profile.py, full-domain migrations,
and the T2 acceptance tests were absent. TASKS already marks T2 superseded by T29.
Neither reserved synth/V003 nor V015 was occupied; historical V002 was not reused.

Kept customer/subscription ids and the [seed, 4242] archetype and [seed, 4243] reason streams.
Replaced separate emission tables with EMISSIONS, shared by cadence, discounts/refunds,
subscription events, quiz retakes/recommendations, support categories and email engagement.
Catalog and fake customer identity are neutral dimensions (not determined by churn class).
Cancellation is the minimum of independent voluntary and payment-failure exponential clocks.
Support categories have 25% random redraws, as do reasons (about 20% observable disagreement
because random draws can select the correct category). Latent truth is stored but never mapped.

All eight views are mapped using T4 column names. PII metadata is validated, while PII CTEs
are forbidden and key-map reads exclude PII views. Full source replacement is transactional.
Profile generation reads physical aggregates only and stores counts, overlapping affected-subscriber
shares and monthly voluntary/involuntary cancellations. The CLI writes the checked-in tiny report.
No raw PII appears in it. Full-scale timing remains T27; re-evaluation remains T30.
