## 2. Design conformance

The design follows ARCHITECTURE §3 layout, §3.1 boundaries, §5.3 tables, §6.1 determinism (`decision_id`, insert-only MERGE) and the autonomous branch of §6.5:
- `agent` returns `Decision` objects and never writes.
- `execution.outbox` writes rows that the decision object renders. It imports `Decision` only under `TYPE_CHECKING`.
- `model` does not import either of them.

I did not edit ARCHITECTURE.md, for two reasons. The built pieces match it. And the parts below are interim thin-path states that later tickets complete by plan, not design changes:
- **AgentContext uses scores only.** ARCH §6.4 and the TASKS slice say the context is built from "scores and features". The thin path's template needs no features, so `agent/context.py` reads RISK_SCORES only, and a code comment records this. Features, history, holdout and engagement come with T11 (`has_quiz`), T12 (guardrails, history) and T13 (policy). No PRD requirement of T10 depends on them.
- **Archetype is `PENDING`.** T7 (archetype scoring) runs in parallel in the same wave. Wiring `archetype`/`archetype_conf` from RISK_SCORES into the context falls to T13, which needs T7 and T10. Until then the log carries `archetype = "PENDING"` and `archetype_conf`, `approved_at` and `outcome_at` NULL. R6.1's AC allows `PENDING` only for response/outcome, so T19's audit-completeness metric (ARCH §6.6) must not count these as complete until T7 and T13 fill archetype. approved_at and outcome_at need a "not applicable / not yet" rule.
- **approve_all mode logs nothing.** ARCH §6.5 says everything goes to approval in that mode. Approvals are T14's work, so for now the runner skips the agent entirely (fail-safe: nothing autonomous). At-risk subscribers not acted on are not yet written to COVERAGE_GAPS (T12).
- **No shard checkpointing of decide (ARCH §6.1 step 6)** and no CANCELLED_STALE re-read at dispatch (§6.5). Both belong to later tickets. Replay safety comes from the deterministic insert-only MERGE.
- **`RUNS.dispatched` counts decisions handled, not rows newly inserted.** On a replay it repeats the first run's number. T14 and T19 should fix the meaning when they compute autonomy and coverage.
