# AI usage log

This repository was implemented with coding agents in Cursor. The agents wrote and edited source, tests, and docs. A human owns the decisions in `docs/decisions.md` and the live Snowflake and demo checks.

What the agents did:

- Drafted the package, SQL migrations, tests, and the operator documents.
- Ran `ruff check src tests` and the default pytest suite locally before each ticket commit.
- Opened GitLab merge requests. GitLab CI, not the agent, is the merge gate.

What was not done:

- No real Thesis customer extract was loaded or sent to a model.
- Training and evaluation used the synthetic generator.
- Email copy stays on the template unless `ANTHROPIC_API_KEY` or `OPENAI_API_KEY` is present together with its SDK. Those keys are not in the repo.
- The demo video was not recorded by an agent. The script is `docs/demo-script.md`.
- A live Snowflake cycle was not claimed from a skipped `snowflake` test.

The default test report is regenerated by `churn report-tests` from the JUnit file CI writes. Slow and scale numbers appear in that report only when those tests were in the JUnit file.

## Snowflake smoke (2026-10-25)

What the agent changed so that run could finish:

- Snowflake statement splitting ignores semicolons that sit inside `--` comments.
- MERGE casts each staged column to the live column type, because an all-null pandas column arrives as NUMBER.
